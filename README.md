# World Football Manager

Juego de manager de fútbol global con enfoque realista en las ligas más importantes del mundo.

## Ligas incluidas (Fase 1)

- **Inglaterra**: Premier League
- **España**: LaLiga
- **Italia**: Serie A
- **Alemania**: Bundesliga
- **Francia**: Ligue 1
- **Argentina**: Liga Profesional
- **Brasil**: Brasileirão Série A

## Estructura del proyecto

```
world-football-manager/
├── data/
│   ├── leagues.json          # Definición de ligas y divisiones
│   ├── clubs/                # Un archivo por liga o por club
│   └── players/              # Datos de jugadores
├── src/                      # Código del juego (próximamente)
├── docs/                     # Documentación
└── README.md
```

## Características planificadas

- Plantillas completas con datos tipo Transfermarkt (edad, posición, valor, estado de cesión, overall, potencial)
- Sistema de fichajes y cesiones
- Gestión de plantilla y tácticas
- Simulación de partidos
- Finanzas del club
- Copas internacionales (Champions, Libertadores, etc.)
- Estructura preparada para agregar más ligas fácilmente

## Estado actual

Proyecto en fase inicial de construcción de datos y estructura.
